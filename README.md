# frugoman/tap

Homebrew casks for my free macOS apps.

```bash
brew tap frugoman/tap
```

| App | What it does | Install |
| --- | --- | --- |
| [SayType](https://frugoman.github.io/saytype-site/) | Hands-free, fully local dictation: click into a text field and talk | `brew install --cask frugoman/tap/saytype` |
| [Impact Capture](https://frugoman.github.io/impact-capture/) | Captures the work that never makes it into a commit, as Markdown | `brew install --cask frugoman/tap/impact-capture` |
| [MeetingFlash](https://frugoman.github.io/meeting-flash/) | Flashes your whole screen right before a meeting starts | `brew install --cask frugoman/tap/meeting-flash` |

Update everything with `brew upgrade --cask`.

The apps aren't notarized, so each cask removes the quarantine flag after install.

If they're useful to you, you can [buy me a coffee](https://buymeacoffee.com/frugoman).
